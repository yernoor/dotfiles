# yernoor's dotfiles

Clone the repo:

```sh
git clone git@github.com:yernoor/dotfiles.git
cd dotfiles
```

## ZSH with catppuccin theme

Installs:

1. Oh-my-zsh with catppuccin theme
2. zsh-autosuggestions plugin

Available catppuccin themes:

- latte
- mocha
- frappe
- macchiato

```sh
chmod +x setup_zsh.sh
./setup_zsh.sh
```
