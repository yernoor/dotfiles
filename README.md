# yernoor's dotfiles

Clone the repo:

```sh
git clone git@github.com:yernoor/dotfiles.git
cd dotfiles
```

## ZSH

Installs:

1. zsh with Oh-my-zsh
2. zsh-autosuggestions plugin

```sh
chmod +x scripts/setup_zsh.sh
./scripts/setup_zsh.sh
```

## ZSH Catppuccin theme

Installs catppuccin theme to zsh

Available catppuccin themes:

- latte
- mocha
- frappe
- macchiato

```sh
chmod +x scripts/setup_catppuccin_theme.sh
./scripts/setup_catppuccin_theme.sh
```

## ZSH aliases

Installs some useful [aliases](zsh/aliases.zsh) to zsh config

```sh
chmod +x scripts/setup_aliases.sh
./scripts/setup_aliases.sh
```
